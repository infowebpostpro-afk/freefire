Blank Name vs. Invisible Space: What Is the Difference?

Invisible Space (Spaced Nickname)

Combines visible letters with one or more invisible filler characters to create clean gaps (e.g. DARK KING). Widely accepted and supported by game text validators.

Blank-Looking Name

Uses solely invisible characters without visible letters, creating an empty nickname in lobbies. Game updates periodically adjust validation rules for empty names.

Why Do Some Invisible Characters Stop Working?

Game publishers regularly patch their client sanitization libraries to prevent spam and name spoofing. When a patch filters standard whitespace (like U+0020 or U+00A0), characters classified in different Unicode categories (such as Hangul Fillers U+3164 or Braille Cells U+2800) continue to operate because the game server processes them as regular script letters.

* Compatibility Note: We do not guarantee permanent 100% acceptance across all game versions. If one character fails, our fallback system provides the other observed alternatives.
