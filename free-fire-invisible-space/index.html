There is no single Unicode character officially named the “Free Fire invisible space.”

U+3164 — Hangul Filler

U+3164 is officially named HANGUL FILLER in Unicode.

It often appears visually blank, which is why it became widely associated with invisible nicknames and spacing tricks.

Despite the common phrase “U+3164 space,” it is technically a Hangul filler character rather than an ordinary keyboard space.

Current third-party sources disagree about its Free Fire compatibility. Treat it as an option to test, not a guaranteed solution.

U+00A0 — No-Break Space

U+00A0 is officially named NO-BREAK SPACE, often shortened to NBSP.

Unlike Hangul Filler, this one really is a Unicode space character. Unicode describes it as the non-breaking counterpart of the ordinary U+0020 SPACE.

It normally has visible spacing width even though there is no visible symbol inside that space.

Some current Free Fire resources recommend U+00A0 as an alternative or current working option. That does not establish permanent compatibility, so verify it in the game before confirming your nickname.

U+2800 — Braille Pattern Blank

U+2800 is officially named BRAILLE PATTERN BLANK.

It looks like empty space in many fonts, but Unicode specifically notes that it does not technically act as a space.

That distinction is useful: a character can look blank without being an ordinary whitespace character.

U+2800 is therefore another useful fallback to test when your goal is a blank-looking gap rather than a specific type of typographic space.

Invisible Space, Invisible Character and Blank Name: What's the Difference?

These terms overlap, but they describe slightly different ideas.

An invisible character is the broadest term. It describes a character that produces little or no visible mark in the context where it is displayed.

An invisible space usually means using one of those blank-looking characters to create separation inside visible text.

For example: PRO[Invisible Character]PLAYER

A blank or invisible name uses blank-looking characters without a normal visible nickname, so the displayed name may appear empty or nearly empty.

The underlying text is not necessarily an empty string. Invisible Unicode characters can still be present even though you cannot see ordinary letters or numbers.

For most players, the difference is practical:

  • Need a gap inside your name? Use the spacing builder or two-word converter.
  • Want a blank-looking result? Try the blank-name option, but verify that your current nickname field accepts the selected character sequence.
